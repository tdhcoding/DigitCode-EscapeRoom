## Agent skills

### Issue tracker

Issues live as GitHub Issues in `tdhcoding/DigitCode-EscapeRoom`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Hai trục: phân loại (`bug`, `enhancement`, `documentation`) và trạng thái
(`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`).
Mỗi issue đã triage mang đúng một nhãn mỗi trục. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
